# Documentation map

Use these entry points instead of reading files in directory order:

- [`current/research_overview_en.md`](current/research_overview_en.md): current English research overview;
- [`current/research_overview_zh.md`](current/research_overview_zh.md): 当前中文研究概览；
- [`current/claim_evidence_ledger.md`](current/claim_evidence_ledger.md): machine-traceable claim boundaries;
- [`current/results_index.md`](current/results_index.md) / [`current/results_index_zh.md`](current/results_index_zh.md): current result artifacts and identities;
- [`current/release_integrity_repair.md`](current/release_integrity_repair.md): documented repair of an outdated code-SHA manifest;
- [Experiment integrity audit](../EXPERIMENT_AUDIT.md): internal A-F checklist with explicit non-independent status;
- [`research_timeline.md`](research_timeline.md): how the research question changed after each result;
- [`decision_log.md`](decision_log.md): evidence-based continue/stop decisions;
- [`code_map.md`](code_map.md): research question → code → artifact map;
- [`history/`](history/): explicitly labeled historical snapshots.

Documents under `history/` record earlier research stages. They may contain superseded protocols, intermediate numbers, or rejected claims and must not be used as the current result.
