# v0.5 public research release

This release reorganizes the repository around the current controlled-study result.

It provides:

- bilingual, result-first README files;
- one canonical machine-readable result source;
- 24-cell experiment registry and evidence hashes;
- explicit current-versus-historical documentation;
- State Dependence v3 CPU contracts without claiming unrun GPU results;
- public-release, figure, configuration, link, secret, and fresh-clone checks.

The release does not add a new downstream experiment or change the reported 24-cell statistics.
