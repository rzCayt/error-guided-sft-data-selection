# AI assistance disclosure

LLM tools, including Codex and external review models, made substantial contributions to this project. Their assistance included code scaffolding, debugging suggestions, test construction, documentation drafts, experiment orchestration support, and adversarial review of protocols and claims.

The project owner was responsible for:

- choosing and revising the research questions;
- authorizing data, compute, protocol freezes, and experiment execution;
- accepting or rejecting proposed research branches;
- inspecting logs, artifacts, audits, and result boundaries;
- deciding what evidence may be reported publicly;
- disclosing uncertainty, negative results, and AI involvement.

The repository does **not** claim that every implementation was written from scratch without AI. AI-generated or AI-assisted code was accepted only after repository tests or artifact checks appropriate to the change. The public release preserves test evidence and maps reported numbers to machine-readable artifacts so that claims do not depend on the model-generated narrative.

Credentials, private notes, restricted dataset text, model weights, and unpublished third-party materials are outside the public repository.
