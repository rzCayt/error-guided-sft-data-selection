# v0.5.1 public research release

This patch release improves all three public figures without changing any
reported result, interval, experimental claim, or State Dependence v3 status.

It provides:

- a main-effects plot with its explanatory note outside the data region;
- a candidate-to-set plot with separated panel titles, labels, and values;
- a State Dependence decision diagram with non-overlapping nodes and text;
- a fail-fast layout check that rejects text overlap and canvas overflow;
- regenerated PNG, vector PDF, figure, and full-release manifests.

The release does not add a GPU experiment or modify the canonical result JSON.
