# 大模型后训练数据选择：从受控实验到可靠测量

[English](README_EN.md) · [结论与边界](CLAIMS_AND_LIMITATIONS.md) · [复现说明](REPRODUCE.md)

## 研究问题

在样本数量、回答监督量和数据组成相同时，有目标地选训练数据，能否比随机选择更可靠地提高模型能力？

已有研究使用 Qwen2.5-1.5B Base 和 LoRA（只训练少量附加参数）的 SFT（用示范答案监督训练）。RDS 是本项目冻结的目标选样策略，Random 是匹配随机基线。回答监督词元是答案中真正参与损失计算的 token，不包含提示和填充。

## 已完成结果

**24组实验**：2 种选样方法 × 4 份名单 × 3 个训练种子，每份 500 个样本；监督预算与“数据来源 × 回答长度”组成匹配。数字统一来自 [规范结果](results/public_summary/main_results.json)。

| 指标 | RDS 减 Random | 95% 区间 |
|---|---:|---:|
| GSM8K 数值准确率 | +0.480个百分点 | [-0.954, +1.889] |
| 三个分布外任务平均准确率 | -0.094个百分点 | [-1.316, +1.149] |

当前设置没有观察到可靠优势；区间同时包含正负效果，不能据此认定没有效果或两方法等效。RDS 名单之间存在较高重合，4 份名单的有效独立性有限；训练种子不会产生新的选样策略。分布外任务为 SVAMP、ASDiv numeric 和 MultiArith。

此前的单样本信号没有转化为稳定的整批训练收益。一个回答组成解释也没有通过预设门槛，已停止追加重训。历史证据、失败记录和冻结配置继续保留。

## 当前探索

依次判断三个假设：**价值是否测得可靠 → 训练后是否需要重新估值 → 单独有用的样本组合后是否冗余、冲突或互补**。样本价值指一次标准化更新前后，独立验证集上的损失下降。

先复用 48 个候选 × 3 个探测种子的冻结可靠性方案；只有通过原门槛，才进入跨状态比较。**GPU 资格测试和正式测量尚未开始。** 新研究独立登记，不能把准备工作当成新结果。

另有 SFT→GRPO 的工程可行性入口。GRPO 会对同题生成多个回答，用相对奖励训练模型；它的 CPU 小模型测试不代表真实 GPU 数学训练已经成功，也不构成论文贡献。[三个月路线与新实验状态](docs/current/research_upgrade_20261013.md)
