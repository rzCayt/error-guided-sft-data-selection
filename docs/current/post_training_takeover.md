# 后训练接管练习

当前状态：待本人完成；AI 的测试通过不是本人能力证明。每周约 10 小时可分成 3 小时学习、3 小时修改调试、2 小时复核、2 小时解释和反馈。

## 第一轮：能解释 SFT

读 `src/eg_sft/training/response_only.py` 和 `overfit.py`。本人解释为什么提示与 padding 标签是 -100，为什么答案末尾必须完整，为什么样本数量相同仍可能有不同监督量。保存一段本人说明，并手算一个短例子的监督 token。

亲自做一次小修改，例如在测试中构造完全截断的答案，说明预期错误并验证；另写自己的修复或参数变更。保存个人 diff 和实际测试输出，不把现有 AI 示例改成“独立完成”。

## 第二轮：能解释 GRPO

读 `src/eg_sft/training/reasoning.py`。对一题四个回答 `[0, 1, 0, 1]` 解释相对奖励；再解释全 0 为什么不能产生有效组内学习信号。回答正确性为实际奖励，格式奖励单独记录且权重为 0，避免把学会格式当成数学能力提升。

亲自补一个奖励边界用例：重复答案标记、答案后还有文字、千分位或负数。训练奖励与评测使用同一严格解析器，无法解析的回答计入分母并记为错误。

## 第三轮：定位失败

选择一个真实失败工件，记录命令、完整 traceback、首先出现错误的输入或状态、一个可证伪的原因、一次修改和原失败的复测。人为构造的练习失败必须注明；不能把 AI 替你完成的诊断记成本人证明。

## 记录模板

| 项目 | 本人填写 |
|---|---|
| 日期与总用时 | 待填写 |
| 本人解释与疑问 | 待填写 |
| 修改 commit 或 diff | 待填写 |
| 测试命令、退出码与输出 | 待填写 |
| 失败原因与验证证据 | 待填写 |
| 仍需帮助的部分 | 待填写 |

达到解释、修改、失败定位三项后，才更新简历里的独立能力描述。AI 可以协助复核，但不能代填个人验收记录。
