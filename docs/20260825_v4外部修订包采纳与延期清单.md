## 4. 当前加速决定

当前冻结Phase 1A继续使用已qualification的单张4090D、batch=1和现有backend。理由：

- 已有正式格均在同一硬件与软件栈下运行；
- 当前显存不是瓶颈，主要耗时是逐题自回归生成；
- 中途改batch、backend或GPU型号会新增不可忽略的hardware/backend block；
- 当前双通道OOD已在不改变单dataset shard和batch的前提下提高GPU利用率；
- 连续控制器已经消除cell之间的人工空转。

如后续明确新增第二张GPU，只接受同型号、同显存、同镜像、同commit、同缓存并完成qualification的4090D/4090；每张卡跑独立cell，不使用DDP，并进行方法—物理卡交叉分配。未经新的明确费用授权，不自动租第二张卡。

## 6. 下一评估后端的桥接门槛

Phase 1A结束后，可以建立batched Transformers或vLLM后端，但必须先对固定base model和至少两个adapter验证：

- raw output token序列；
- parsed answer；
- aggregate accuracy；
- strict/fallback parser状态；
- generation length；
- GPU时间、墙钟时间、显存和单格费用。

只有输出等价且每个审计通过格子的实际成本显著下降，才在新阶段统一切换后端；不能把不同后端的部分结果直接混为同一确认矩阵。
