# B=500 三策略、三随机种子统一入口

更新日期：2026-07-29

## 这个入口做什么

统一入口会检查并列出以下 9 项正式任务：

- 3 种选样方法：`random`、`rds_all`、`rds_error`；
- 3 个训练随机种子：17、29、41；
- 每种方法使用同一个 500 条样本名单完成三个训练种子；
- 九项任务共用完全相同的模型、训练参数、评估参数和数据版本。

这里的“随机种子”是控制模型初始化、训练数据打乱等随机因素的固定编号。
同一个种子下比较三种方法，可以减少“只是随机性不同”造成的干扰。

入口文件是：

`scripts/preflight_b500_formal_matrix.py`

当前入口只做 **dry-run（干跑）**。干跑的意思是：只检查文件并打印未来要执行的
命令，不加载模型、不占用 GPU，也不开始训练。

## 它会检查什么

1. H1a 是否确实按预注册门槛通过；
2. 模型、数据、训练配置和训练脚本的 SHA-256 是否仍与冻结版本相同；
3. 500 条入选样本是否都来自冻结的 10,000 条候选池；
4. 每个入选样本是否仍有可训练的回答词元；
5. 入选名单中的方法名、预算、选样种子和样本 ID 哈希是否一致；
6. 九个“方法 × 训练种子”组合是否各出现一次且没有重复；
7. 九项任务是否只允许改变方法、入选名单和训练随机种子。

“selection manifest”可直译为“选样清单”。它不是只存 500 个名字，而是同时保存
每条样本的来源位置、内容哈希、词元审计和完整名单哈希，用来防止名单在训练前后
被悄悄替换。

## 当前检查结果

当前干跑能正确生成 9 项任务，但整体状态是：

`BLOCKED_INCOMPLETE_SELECTION_FREEZE`

直白地说，就是“九项任务的结构已经准备好，但两份 RDS 选样清单还没有生成和
冻结，所以一项正式训练都不应开始”。

| 方法 | 当前状态 | 原因 |
|---|---|---|
| `random` | 选样清单已通过 | 500 条名单、内容和哈希完整 |
| `rds_all` | 阻塞 | 尚无完整 10,000 候选池上的 500 条选样清单 |
| `rds_error` | 阻塞 | 尚无完整 10,000 候选池上的 500 条选样清单 |

即使 `random` 已经准备好，正式矩阵中的 random 三个训练也暂不启动。这样可以在
看到任何正式比较结果之前，一次性冻结三种方法的入选名单，避免根据中途结果修改
RDS 名单。

此前完成的 random、seed 17 是“工程闭环验证”，不是这 9 项正式比较中的结果；
两者用途不同，不混在正式三随机种子统计中。

## 为什么任务顺序不是简单的连续三遍

任务顺序在三个种子之间轮换方法的先后位置：

- seed 17：random → rds_all → rds_error；
- seed 29：rds_all → rds_error → random；
- seed 41：rds_error → random → rds_all。

这样做是为了让每种方法各有一次处在第一、第二和第三位置，减少机器状态、缓存和
运行时段总是与某一种方法绑定。这个顺序已经写进配置，不能在看到结果后调整。

## 如何运行干跑

在仓库根目录执行：

```powershell
python scripts/preflight_b500_formal_matrix.py
```

如需保存报告，可使用一个尚不存在的新文件名：

```powershell
python scripts/preflight_b500_formal_matrix.py `
  --output results/research_public_gsm8k_v1/b500_formal_matrix_preflight_v1.json
```

脚本使用“只新建、不覆盖”的写入方式。如果目标文件已经存在，它会直接拒绝，
防止后一次检查覆盖前一次证据。

## 下一项研究代码工作

下一步不是训练，而是：

1. 在完整 10,000 条可训练 Tulu 候选上计算同一版本的 RDS+ 表示和排序；
2. 分别按 all-query 和 error-query 排名冻结前 500 条；
3. 生成 `rds_all` 和 `rds_error` 两份选样清单；
4. 把两份清单的 SHA-256 写入矩阵配置；
5. 重新运行干跑，只有全部 9 项都显示
   `READY_FOR_MANUAL_INVOCATION` 后，才允许一次启动一项并由当前对话人工监控温度。

本入口本身不支持“一键连续跑九项”，这是有意的温控和审计边界。
